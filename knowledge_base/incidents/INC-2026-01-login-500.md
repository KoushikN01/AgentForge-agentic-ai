# INC-2026-01 — Login endpoint returning 500

**Status:** Resolved
**Severity:** High

## Summary

`POST /api/auth/login` began returning HTTP 500 for all requests shortly
after a deployment.

## Root cause

The deployment environment was missing the `JWT_SECRET` environment
variable. The token-signing code raised a `KeyError` at request time,
which the API layer did not catch, resulting in a 500 response.

## Fix

Set `JWT_SECRET` in the deployment environment and redeployed. Added a
deployment-checklist step (see `deployment_notes.md`) to verify required
environment variables are set before deploying.

## Lessons learned

Required environment variables should be validated at application
startup, not discovered the first time an affected endpoint is called.
